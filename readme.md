# Web Development Learning

A beginner-friendly web development learning repository covering frontend and backend fundamentals through structured lessons and hands-on projects.

This repository contains presentation materials and practical source code for each learning session. Participants will progressively develop a web application while learning the fundamentals of web development.

## 🎯 Learning Objectives

By completing this learning program, participants are expected to:

- Understand the fundamentals of web development.
- Build website structures using HTML.
- Create and style layouts using CSS.
- Develop interactive web pages using JavaScript.
- Understand basic programming concepts and problem-solving.
- Develop server-side applications using PHP Native.
- Manage relational databases using MySQL.
- Connect PHP applications to MySQL using PDO.
- Implement CRUD operations.
- Understand authentication and session management.
- Integrate frontend and backend technologies into a functional web application.

## 📚 Learning Roadmap

The learning program consists of six sessions, starting from frontend fundamentals and progressing toward backend development and database integration.

### Meeting 01 — Introduction to Web Development & HTML Fundamentals

**Topics:**
- Introduction to Web Development.
- How Websites Work.
- Frontend vs Backend.
- Introduction to HTML.
- HTML Tags, Elements, and Attributes.
- Basic HTML Document Structure.
- Headings, Paragraphs, Links, and Images.
- Lists and Basic HTML Elements.
- Introduction to HTML Forms.

**Practical Project:**

Create a simple Personal Profile Website using HTML.

**Expected Outcome:**

Participants can build a basic personal profile page containing personal information, profile pictures, education, hobbies, and contact details.

### Meeting 02 — HTML Containers & CSS Fundamentals

**Topics:**
- Introduction to CSS.
- The Relationship Between HTML and CSS.
- Inline, Internal, and External CSS.
- HTML Container Elements.
- Understanding `<div>`, `class`, and `id`.
- CSS Selectors.
- CSS Properties and Values.
- Colors, Backgrounds, and Typography.
- CSS Box Model.
- Margin, Padding, and Border.
- Introduction to Flexbox.
- Hover Effects and Transitions.

**Practical Project:**

Improve the Personal Profile Website from Meeting 01 by applying CSS styling and layout techniques.

**Expected Outcome:**

Participants can organize HTML elements and create visually appealing website layouts using CSS.

### Meeting 03 — JavaScript Fundamentals & DOM Manipulation

**Topics:**
- Introduction to JavaScript.
- JavaScript in Web Development.
- Variables and Data Types.
- Operators.
- Conditional Statements.
- Loops.
- Functions.
- Arrays and Objects.
- Introduction to DOM (Document Object Model).
- Selecting HTML Elements.
- Event Listeners.
- DOM Manipulation.
- Basic Form Validation.

**Practical Project:**

Add interactive features to the existing Personal Profile Website.

**Expected Outcome:**

Participants can use Vanilla JavaScript to manipulate HTML elements and create basic website interactions.

### Meeting 04 — PHP Fundamentals & Backend Development

**Topics:**
- Introduction to PHP.
- Client-Side vs Server-Side Programming.
- How PHP Works.
- PHP Syntax.
- Variables and Data Types.
- Operators.
- Conditional Statements.
- Loops and Functions.
- HTML Form Processing.
- GET and POST Methods.
- Introduction to `include` and `require`.
- Basic Input Validation.

**Practical Project:**

Integrate PHP into the existing project and create a contact form that processes user input on the server.

**Expected Outcome:**

Participants understand basic server-side programming and can process submitted form data using PHP.

### Meeting 05 — MySQL, PDO & CRUD Operations

**Topics:**
- Introduction to Relational Databases.
- Database, Tables, and Columns.
- Primary Keys.
- Basic SQL Commands.
- Creating Databases and Tables.
- Connecting PHP to MySQL.
- Introduction to PDO.
- Prepared Statements.
- CRUD Operations (Create, Read, Update, Delete).
- Retrieving and Displaying Database Records.

**Practical Project:**

Connect the contact form to a MySQL database and implement basic data management functionality.

**Expected Outcome:**

Participants can connect PHP applications to MySQL using PDO and implement basic CRUD operations.

### Meeting 06 — Authentication, Project Integration & Final Evaluation

**Topics:**
- Introduction to Authentication.
- Login and Logout Functionality.
- PHP Sessions.
- Password Hashing and Verification.
- Basic Access Control.
- Project Directory Organization.
- Reusable Components.
- Frontend and Backend Integration.
- Basic Application Security.
- Testing and Debugging.
- Project Presentation.

**Practical Project:**

Complete the Personal Profile Website by implementing an Admin Dashboard with authentication and message management functionality.

**Expected Outcome:**

Participants can integrate the concepts learned throughout the program into a functional web application.

## 🚀 Final Project

### Personal Profile Website

The final project is a personal profile website developed progressively throughout the six learning sessions.

**Planned Features:**

- Personal Profile Page.
- Profile Image and Personal Information.
- Responsive Website Layout.
- Interactive UI using JavaScript.
- Contact Form.
- Basic Form Validation.
- Message Storage using MySQL.
- Admin Login and Logout.
- Admin Dashboard.
- Message Management (CRUD).

## 📖 Learning Methodology

This learning program applies a project-based and hands-on approach.

1. **Understand the Concepts** — Learn the fundamentals before writing code.
2. **Learn by Doing** — Apply concepts through practical coding sessions.
3. **Build Progressively** — Develop and improve the same project throughout the sessions.
4. **Problem Solving** — Practice logical thinking and debugging.
5. **Evaluate and Improve** — Review and improve the application based on feedback.

## 📌 Prerequisites

No advanced programming experience is required.

Participants are encouraged to have:

- A computer or laptop.
- A modern web browser.
- Visual Studio Code or VSCodium.
- XAMPP for local PHP and MySQL development.
- Basic computer operation skills.

## 📝 Notes

- This learning program is designed for beginners.
- Each session is planned for approximately 1–2 hours.
- Learning materials are organized progressively.
- JavaScript focuses on Vanilla JavaScript rather than frontend frameworks.
- PHP Native is used to introduce backend development.
- The final project may be adjusted according to participants' learning progress.
